# DAS DORF

Social-Deduction-App für iPhone/iPad (Android später): Rollen, geheime Chats, Dorfrat und Quests in der App – Reden, Bluffen und Zeigen im echten Raum.

Verbindlich: `CLAUDE.md`, `docs/GAME_DESIGN.md`, `docs/STYLE_GUIDE.md`. Architektur: `docs/ARCHITECTURE.md`. Offene Interpretationen: `docs/OPEN_DECISIONS.md`. Lokale Einrichtung: `LOCAL_SETUP.md`.

```bash
npm install
npm test            # Engine, Server, App-Logik, DB/RLS
npm run typecheck
```
