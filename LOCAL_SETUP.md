# LOCAL SETUP (kurz)

Für lokale iOS-Entwicklung auf dem Mac:

1. Aktuelles stabiles **Xcode** aus dem Mac App Store installieren.
2. Xcode einmal öffnen und iOS-Simulator-Komponenten installieren.
3. Node.js, Git und Claude Code müssen verfügbar sein.
4. Skills aus `SKILLS.md` installieren.
5. Diesen Ordner als Projektwurzel öffnen und den Inhalt von `START_PROMPT.md` an Claude Code geben.

Expo Development Builds statt Expo Go verwenden, sobald native Funktionen benötigt werden.
